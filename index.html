ZeroBlockBridge

A desktop app that takes the complexity out of running a Minecraft server.
Auto-healing, tunneling, backups, and mod management — all in one place.

Download Documentation →

Click anywhere on the background

Everything you need

ZBB handles the hard parts so you can focus on playing.

⚡

Auto-Healing

Watchdog detects crashes, zombie processes, and lag spikes. Exponential backoff restarts with stability tracking — your server comes back on its own.

🌐

Instant Tunneling

Integrated Playit.gg agent gives your server a public address with no port forwarding. Works behind any NAT — friends connect in seconds.

☕

Smart Java Management

Detects the required Java version from bytecode, downloads the right JDK automatically to a local cache. Never touches your system Java.

💾

Automated Backups

Schedule full or world-only ZIP backups with configurable intervals and retention counts. One-click restore with a safety copy before every restore.

🧩

Modrinth Mod Browser

Search, install, and update mods directly from Modrinth. Version selector, update checker, and per-server mod management built in.

🔒

Command Sanitizer

An 80+ command allowlist blocks shell injection and dangerous ops. Runs shell=False with strict argument lists — no surprises.
