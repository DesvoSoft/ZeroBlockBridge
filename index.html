Server creation

Start from a modpack or a world you already have

The creation wizard reads a Modrinth .mrpack or a modpack's Server Pack and sets the engine, the Minecraft version and the exact loader build for you. Mods and configs install while the server is built. On the world step, bring a save from .minecraft/saves or a world .zip downloaded from CurseForge.

Running it

The server keeps itself up while you play

Everything a small server needs day to day, in one window and without a terminal.

Friends join without port forwarding

A built-in Playit.gg tunnel gives the server a permanent public address. Share it and your friends can join.

The right Java, installed for you

ZBB works out which Java the server needs, from Java 8 up to Java 25 for Minecraft 26.x, and installs it next to the app. Your system Java is left alone.

Restarts after a crash

A watchdog restarts a crashed server with backoff, detects a frozen one and flags lag spikes. Each crash is saved as a report.

Mods that update safely

Search and install mods and plugins from Modrinth with their dependencies. Every update takes a full snapshot first, so a bad one is a single restore away.

One list of players

Whitelist, operators, bans and kicks in one Players tab, with skin heads, last seen and playtime. The header shows uptime, RAM use and who is online.

Backups on a schedule

Scheduled, manual and pre-update backups are kept apart, so rotating automatic ones never deletes yours. Restore or delete each one with a click.

Console commands are checked

Commands are matched against an allowlist before they reach the server. If one is blocked, a notice says which command and why.

Several servers, one at a time

Keep a server per modpack or per group of friends. You can open and configure any of them while another one is running.

Also included: server templates, .zbbpack export to move a server to another PC, Discord notifications, closing to the system tray while servers keep running, and light, dark or system theme.

Getting started

From download to a server your friends can join

  1. Install

    Run the download and choose Install on this PC. No admin rights needed. You get Start menu and Desktop shortcuts and an uninstaller in Windows Settings. Prefer a single folder? Pick Portable.

  2. Create a server

    Pick an engine and a version, or import a modpack. Set RAM, game rules and the world, then review everything on one summary page before ZBB builds it.

  3. Start and share

    Press Start. ZBB accepts the EULA, launches with tuned JVM flags and opens the tunnel. Copy the address and send it to your friends.

Get ZeroBlockBridge

Free and open source under AGPL-3.0. Windows 10 and 11, with an experimental Linux build. No Python needed.

  • Windows SmartScreen warns about the file because it is not code-signed yet. Choose More info, then Run anyway, or build it from source yourself.
  • Checksums for every file are published next to it on the release page as .sha256.
